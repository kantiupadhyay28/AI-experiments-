# Aark Bank — Inclusive Banking UX

A mobile banking prototype demonstrating multimodal, sign-language-first UX design for users across the disability spectrum (permanent → temporary → situational).

## Features

- **3 login methods**: Passkey, Face ID, Sign Language authentication
- **Sign language amount entry**: ASL-inspired number gestures (0–9) for entering transfer amounts
- **Sign language PIN entry**: Confirm transactions using hand gestures
- Simulated gesture detection with confidence meters and landmark tracking UI
- Dark-theme phone-frame mockup, no images required

## Stack

React 19 · Vite 8 · Tailwind CSS v4

## Run locally

```bash
npm install
npm run dev
```

## Design intent

Built on the Microsoft Inclusive Design model — solutions for permanent disabilities create better experiences for temporary and situational disability cases too.
